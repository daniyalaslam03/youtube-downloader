# YouTube Downloader

A Windows desktop application for downloading YouTube videos and playlists with quality selection, audio extraction, download history, and dependency management.

## Features

- Download individual YouTube videos.
- Download complete playlists.
- Select video quality.
- Extract audio.
- Resume interrupted playlist downloads.
- Keep track of download history.
- Retry previous downloads.
- Manage application settings.
- Update bundled dependencies.

## Requirements

- Windows 10 or later.
- Internet connection.

## Installation

1. Visit the [Releases](https://github.com/daniyalaslam03/youtube-downloader/releases) page.
2. Download the latest `YouTubeDownloader-Setup.exe`.
3. Run the installer.
4. Follow the installation instructions.
5. Launch YouTube Downloader.

## Technology

- yt-dlp
- FFmpeg
- FFprobe
- Node.js
- PowerShell
- Windows Batch
