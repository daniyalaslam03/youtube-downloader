# Changelog

All notable changes to YouTube Downloader are documented here.

## [1.0.1] - 2026-10-31

### Added
- First-launch default download folder selection.
- Windows Downloads is the initial folder shown in the folder picker.
- Selected download location is saved in `config/settings.json`.
- The app asks for a new location if the saved folder is unavailable.

### Changed
- Default video merge container is MP4.
- Installer grants standard users write access to the configuration, data, and logs folders.

## [1.0.0] - 2026-10-31

### Initial Release

- Individual YouTube video downloads.
- Playlist downloading.
- Video quality selection.
- Audio-only downloads.
- Automatic FFmpeg integration.
- Node.js JavaScript challenge support.
- Interrupted playlist download recovery.
- Download history management.
- Download retry functionality.
- Application settings.
- Dependency updater.
- Windows installer with custom application icon.
